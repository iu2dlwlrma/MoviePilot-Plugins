# 站点刷流

适用于 MoviePilot 3.0.0 及以上版本。每项任务绑定一个站点，工作台提供站点优先级、选种诊断、托管种子和上传统计。

## 全局统一配置

在全局设置中统一选择下载器、保存目录、刷新周期、选种与删种规则。新建站点默认继承这些参数，只需选择站点；需要差异时勾选对应的覆盖字段，允许单独设置为关闭或不限。

保存全局参数会作用于正在继承的字段。“应用到全部站点”会清除所有共享参数的站点覆盖，保留站点身份、启停、新手考核、时区偏移、H&R 标记、跳过下载提示和标签。已有任务迁移时把与全局不同的值保留为覆盖，避免丢失站点规则。存在未删除托管种子的任务须保留原下载器，处理完成后才能切换，防止丢失关联。

插件不限制下载数量或上传下载速度，下载器负责排队和带宽。旧数量、速度门槛不再生效。全局与任务空间上限按所有未删除种子的完整大小计算，排队任务也预留空间。相同下载器和 Hash 的记录只计一次；qBittorrent 接受任务后暂未返回 Hash 时先保留空间，待唯一标签可识别后关联。

## 站点轮转与选种

全局可选择“多站并行”或“单站驻留”。单站驻留时，每站默认连续 24 小时接收新增种子，时间从被选中时开始计算；驻留小时数可统一设置或逐站覆盖。切换只影响新增种子，昨天的种子继续下载、做种与检查，仍按原有删种条件处理。分享率变化不会提前结束当前驻留。重启保留当前站点和截止时间，调度器在到期后的下一次分配（通常 30 秒内）切换；停机跨过多个周期时恢复后选择下一站，不追补离线轮次。

每个轮次中，各启用站点先各获得一次驻留机会，尚未轮到的站点按以下顺序选择：

1. 手动标记为“新手考核中”的站点；可填写截止时间，到期后自动失效。宿主没有提供统一考核状态，不能自动识别。
2. 当前站点分享率低于目标的站点，目标默认 2，可全局或逐站调整。
3. 分享率已达标或统计未知的站点，按最近成功加种时间轮转。

多站并行时，到期任务使用相同优先级，每轮每项任务先添加一个符合条件的种子，再继续下一轮，直到候选用完或空间不足。单站驻留只为当前站点执行这一步，其余任务等待轮到后执行。每个到期任务每次调度只获取一次候选列表；重复调度受锁保护。分享率达标后仍继续轮转。站点未到刷新时间、未启用、处于运行时间段外或没有合格候选时不会强制取种；无候选不会提前换站。当前站点被停用或删除时，下一次分配选择其他启用站点。

分享率使用宿主最近的站点统计，界面显示更新时间和陈旧状态；上传、下载与分享率全为零视为未知。下载量为零且上传量大于零视为无限，下载量大于零但分享率缺失或为零时按上传量/下载量推算。

默认筛选做种人数 1–50、下载人数至少 1、下载人数/做种人数至少 0.1。做种人数单值表示上限，下载人数单值表示下限；两者都支持闭区间。启用人数筛选时，无法识别的人数不会视为通过。合格种子优先选择需求人数多、做种竞争低且较新的种子，需求得分每六小时衰减一半。发布时间保留原始时区，无时区时按宿主时区及站点偏移处理；启用发布时间筛选时，未知日期不会通过。还可配置免费促销、H&R 排除、标题规则、体积、发布时间和订阅排除。人数只反映抓取时的需求，不能保证后续上传量。

## 删种与保护

普通删种和动态空间清理跳过从未开始下载的任务。判断依据包括下载器明确下载状态、已完成字节、累计下载流量与持久的已开始标记，不按添加时间或排队时长推断。下载超时从实际开始或首次观察到开始的时间计算。

启用促销清理时，免费结束前默认 10 分钟删除未完成种子及未完成文件，可统一调整提前分钟数。这个例外也适用于从未开始的排队任务；已完成种子不受此规则删除。新增候选已进入提前清理窗口时直接跳过。带时区的促销时间按真实时间换算，无时区时间按站点偏移处理。站点未提供有效结束时间时无法安排精确提前清理。

H&R 与删除保护标签仍生效；建议保留 `MOVIEPILOT,H&R`。精确到期检查与周期检查共同执行，下载器故障、保护规则或任务正在执行可能延迟删除，应给提前量留出余地。

部分 NexusPHP 站点普通下载地址返回 HTML 提示页，可在该站点开启“跳过下载提示”，追加 `letdown=1`。有效登录信息仍是下载前提。

## 仓库与安装

源码位于 `plugins.v3/brushflow`，市场清单位于根目录 `package.v3.json`。发布包保留 `brushflow/` 顶层目录及 `dist` 前端产物。

将本仓库作为插件市场来源，通过宿主来源切换选择本仓库版本。同一 `BrushFlow` 插件 ID 保留既有配置和记录，避免同时安装两个副本或被其他来源自动更新覆盖。

## 开发与验证

在具有宿主依赖 Pydantic 2 的 Python 环境中，于仓库根目录执行 `python -m unittest discover -s tests -v`。测试隔离宿主入口，不连接实际数据库、站点或下载器。

前端使用已有 Vue、Vuetify 与 Vite 依赖，在插件目录执行 `npm install`、`npm run build`，产物位于 `dist/assets`。后端、插件包和市场清单版本保持一致。主分支通过测试后，发布工作流按市场清单打包。
