# 站点刷流

适用于 MoviePilot 3.0.0 及以上版本。每项任务绑定一个站点和下载器，独立设置刷新周期、CRON、时间段、选种条件、删种规则和统计。工作台包含完整页面、配置页和仪表板。

## 下载名额与轮转

设置全局同时下载任务数后启用公平轮转。建议全局为 `5`，各任务上限为 `1`，再根据存储和网络负载调整全局值。

- 到期任务进入等待队列，每 30 秒检查一次可用名额；重复刷新不会改变排队顺序。
- 已到期站点按最近成功加种时间从早到晚分配，尚未成功过的站点优先。同站点的多个任务共用一个未完成名额，每轮每站最多新增一个种子。
- 暂停、排队、校验及异常的未完成刷流种子仍占名额；完成下载后释放名额，继续做种不占名额。既有积压不会被自动删除或暂停。
- 无候选、筛选不匹配或达到分享率目标时跳过该站，按其刷新周期再次尝试。站点未到刷新时间、未启用或不在运行时间段内时不会强制取种。
- 手动刷新也遵守名额与轮转规则。下载器读取失败时保留等待任务，恢复后重试。
- 成功加种时间持久保存，重载不重置站点优先级。重载后等待任务按各自刷新周期重新进入队列。

全局数量留空或为 `0` 时不限制全局数量，保留各任务自身数量限制。全局与任务容量、带宽、免费筛选、H&R 和订阅排除规则继续生效。公平轮转提供选种机会，不能保证每站都有符合条件的种子或上传需求。

工作台显示“等待”的任务可能正在等待下载名额。已暂停或异常的未完成种子需要恢复、完成或由用户处理后才能释放名额。

## 下载提示

部分 NexusPHP 站点的普通下载地址返回 HTML 提示页。对此可在任务中开启“跳过下载提示”，插件会追加 `letdown=1`。有效的站点登录信息仍是下载前提。

## 数据与保护

任务 ID、现有托管数据和下载器标签保持兼容；同站点多任务建议使用不同标签。计数按下载器与种子 Hash 去重，同时识别任务标签、旧版全局标签和托管记录。

动态删种、免费到期检查和保护标签由任务原有规则决定。轮转本身不删除种子。推荐保留 `MOVIEPILOT,H&R` 保护标签，并避免对排队任务使用过短的下载超时删除规则。

## 仓库与安装

插件位于 `plugins.v3/brushflow`，市场清单位于根目录 `package.v3.json`。发布包保留 `brushflow/` 顶层目录及 `dist` 前端产物。

将本仓库作为插件市场来源，通过宿主的来源切换功能选择本仓库版本。使用相同的 `BrushFlow` 插件 ID 可保留既有配置；避免同时安装两个副本或继续从其他来源自动更新同一插件。

## 开发与验证

在仓库根目录执行 `python -m unittest discover -s tests -v`。测试使用标准库隔离宿主入口，不连接实际数据库、站点或下载器。

前端使用插件已有的 Vue 与 Vite 依赖，在插件目录执行 `yarn build`，产物位于 `dist/assets`。后端、插件包和市场清单的版本需保持一致。主分支通过测试后，发布工作流按市场清单打包。
