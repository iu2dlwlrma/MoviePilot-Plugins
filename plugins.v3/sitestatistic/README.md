# 站点数据统计

## 用途

提供今日增量、累计汇总和自然月上传 / 下载增量。插件 ID 为 `OriechoSiteStatistic`，作者为 oriecho，使用独立的 `oriechositestatistic_` 配置前缀。默认禁用；不读取、迁移或覆盖官方站点数据统计插件的配置，不操作下载器。

本插件基于 `SiteStatistic` 1.9.7 独立派生，保留原作者 lightolly、jxxghp 的站点图表、PB 格式化和低精度提示能力。新插件维护者：[oriecho](https://github.com/iu2dlwlrma)。代码许可见 [LICENSE](./LICENSE)。

## 目录与文件

- `__init__.py`：MoviePilot 插件入口、原生 JSON 配置 / 仪表板 / 详情页面和刷新事件通知。
- `monthly.py`：只读每日快照的月增量计算，不依赖其他业务项目。
- `LICENSE`：GNU General Public License v3。

## 部署与运行

通过本个人插件仓库安装 `OriechoSiteStatistic`。它与官方插件使用不同 ID，可以独立安装、启停和卸载；安装后先进入配置启用。

本插件没有独立容器、systemd 单元或定时刷新任务，运行于宿主 MoviePilot。站点快照由宿主原有刷新机制保存。“立即运行一次”会在保存配置后请求一次站点数据刷新；再次保存、重载或停止插件时回收旧调度器。更新本插件不会安装或更新官方插件。

## 配置与入口

- **仪表板组件**：今日数据、汇总数据、本月数据、所有数据；本月和所有数据模式都按总计、本月、今日的顺序同时展示三组汇总，今日 / 汇总独立模式保留原有图表或卡片。
- **数据刷新时发送通知**：不发送、今日增量数据、累计全量数据、月增量数据。仅在插件启用且宿主完成全量站点刷新时发送；月通知按完整正文去重，内容改变后可再次发送。
- **查看数据**：顶部同时展示总计、本月和今日三组汇总，保留原有日增量图；底部只有一张所有站点列表。在原站点、日期、用户名、等级、累计上传 / 下载、分享率、魔力、做种数及体积列后，增加今日上传 / 下载、本月上传 / 下载、本月统计起止和覆盖状态。宽表格在内部横向滚动，可通过键盘聚焦滚动区域；没有最新快照时保留三组汇总与同一张表，缺数据以 `—` 标记。

`refresh_by_domain` 保留宿主插件 API 入口，使用宿主 API Token 校验，仅在显式请求时刷新指定站点。不提供新的未鉴权接口。

源码目录为 `plugins.v3/sitestatistic`；目录名不参与身份匹配。插件类名 / ID `OriechoSiteStatistic`、配置前缀和 API 身份保持不变，已保存的本插件配置继续使用。手动发布 1.1.0 时将生成标签 `OriechoSiteStatistic_v1.1.0` 和安装包 `oriechositestatistic_v1.1.0.zip`；仓库重置后旧发行包已清空，须先重新发布才能从本仓库安装或更新。

## 数据与依赖

自然月按 MoviePilot 的 `settings.TZ` 划分，每次最多读取上月最后一天和本月至今的每日快照，共 32 个日期。仅统计启用站点，按 **域名 + 用户 ID** 匹配账号；同名站点不会合并。

新增的今日汇总与表格日增量只使用当前日期和前一日同账号的有效快照；明确存在的零值基线可以比较。缺基线、最近快照并非今日、账号变化或计数下降时显示 `—`，不把跨多日差值当作今日流量。月数据按域名和用户 ID 接入原站点行，账号不一致时不拼接另一个账号的月值。既有今日独立仪表板及通知模式保持兼容。

完整月增量使用上月最后一天的有效快照作为基线，用当月最新有效快照减去该基线。上传和下载为零的基线有效。缺少上月末基线时，至少需要两天有效快照，按月内第一天到最后一天计算并标注“缺月初基线；部分统计”；只有一份时显示“不足以计算”，不伪造零增量。每站日期单独展示，汇总范围不意味着所有站点覆盖相同日期。

错误、空值、非有限数、负数和日期不符的快照不参与比较。累计、今日、月统计与明细共用快照选择规则：同一域名同日存在多份快照时，先按更新时间、记录 ID 取最新有效快照，再按账号比较；不会挑选已经换号之前的旧快照，也不会越过换号日期向前寻找同账号。月内账号变化或计数下降时，该站标为无法比较并从月合计排除；汇总显示可比较站点数和部分统计状态。日基线读取失败时保留已获取的最新累计数据，并明确标记日基线读取失败；月日期读取失败同样保留可用月数据并标记。

`≈` 表示两期读数疑似经过 PB 舍入，不能从舍入结果还原真实期间增量。读数不变会显示实际增量未知；插件不平滑、不推算缺失流量，也不改写宿主原始数据。整数计数保留整数差值精度；宿主已保存为浮点数或站点已舍入的数据无法恢复额外精度。

依赖 MoviePilot 已有的站点数据接口、pytz、APScheduler 和 UI 组件，不新增外部服务或 Python 包。插件配置及通知指纹由宿主插件存储隔离保存。

## 日常维护

状态从 MoviePilot 插件管理页查看；启停在本插件配置中执行。日志沿用 MoviePilot 日志入口，可按“站点数据统计”查询。无需额外执行独立启动或日志命令。

缺少月初基线时，等待快照不会补出过去数据，页面会持续显示实际覆盖范围；到下个月具备月末和月内有效快照后可形成完整比较。站点更换账号或累计计数重置后，本月标记无法比较，避免混入旧账号数据。

## 验收

在仓库根目录运行：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 tests/test_site_statistic_monthly.py
```

离线回归覆盖时区月界、跨年 / 闰月、合法零基线、缺基线 / 单份快照、同名域名隔离、换号 / 计数下降、无效快照、同日多份快照、整数精度、PB 提示、月通知去重、禁用通知、调度器回收以及原今日 / 累计模式。宿主接口以离线边界替代，不会调用生产站点或发送真实通知。

安装后的交互验收需在 MoviePilot 中确认配置可保存、本月与所有数据仪表板、详情实际日期、手机表格滚动和刷新通知。本仓库测试不等同于已在生产安装。
