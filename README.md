# MoviePilot-Plugins

本仓库保存 MoviePilot 插件源码、市场索引、图标、测试和相关文档。

上游项目：[MoviePilot 官方插件仓库](https://github.com/jxxghp/MoviePilot-Plugins)。

## 使用方法

通过 MoviePilot 插件市场浏览、安装和更新插件。
仓库地址使用 `PLUGIN_MARKET` 配置，多个地址用逗号分隔。
插件市场只读取 GitHub 仓库的 `main` 分支。
